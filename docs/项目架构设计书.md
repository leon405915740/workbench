# 记账App 项目架构（精简版）

## 项目概述
- **定位**：个人自用，数据本地存储，AI 辅助记账
- **核心理念**：MVP 优先，数据安全优先，砍掉过度设计
- **核心特性**：智能记账(自然语言→AI解析→自动分类)、多账单处理、分类管理(支出9类+收入8类)、自动学习、统计分析、数据安全

## 技术栈
- **UI**：Kotlin 1.9+ / Jetpack Compose / Material3 / ViewModel+StateFlow
- **数据**：Room 2.5.2(禁2.6.1) / DataStore Preferences / OkHttp+Retrofit
- **AI**：DeepSeek API + 本地正则兜底 + 关键词映射匹配
- **工具**：AppLogger(统一日志) / TimeUtils / AmountUtils / CsvUtils / KeywordExtractor

## 架构（三层极简）

```
UI层: ChatScreen / DashboardScreen / SettingsScreen → MainViewModel(UiState+StateFlow)
  ↓
Domain层: IntentRouter(意图路由) → PlanBuilder(计划生成) → PlanValidator(校验) → PlanExecutor(执行)
  ↕        MappingMatcher(映射匹配) / ClassificationService(分类匹配)
  ↓
Data层: AppRepository → ExpenseDao/IncomeDao/CategoryDao + DataStore + DeepSeekApi → AppDatabase(Room)
```

## 核心数据流
```
用户输入 → IntentRouter.route()
  1. MappingMatcher.match() → 命中关键词映射(confidence>0.9)
  2. AmountUtils.extractAmounts() → 正则提取+分类
  3. PlanBuilder.buildPlan() → AI解析兜底
  → BillExecutePlan → UI预览 → 用户确认 → PlanExecutor.execute() → Room写入
```

## 关键约束
- **所有数据库写入**必须通过 PlanExecutor.execute()，禁止直接调用 DAO
- **时间字段**必须由本地 TimeUtils 生成，AI 禁止输出时间戳
- **PlanValidator 两层校验**：生成侧(PlanBuilder内) + 执行侧(PlanExecutor入口)
- **日志**：统一 AppLogger，必须携带 requestId+节点名，敏感信息脱敏
- **禁用**：EventRouter/ActionBus/AgentCore/UIEventStream、fallbackToDestructiveMigration()、GlobalScope

## 数据库（Room v6）

**表结构**：
- `expenses`：id, amount(分), category, subCategory, merchant, recordTime, note, createdAt, categoryId, subcategoryId
- `income`：同 expenses 结构
- `categories`：id, type(expense/income), name, parentId, sortOrder, isSystem, createdAt, updatedAt — 索引: UNIQUE(name,type,parentId)
- `category_mappings`：id, keyword, type, categoryId, subcategoryId, source(MANUAL/AUTO), enabled, hitCount, createdAt, updatedAt, lastHitAt — 索引: UNIQUE(keyword,type)

**迁移策略**：禁用fallbackToDestructiveMigration，简单变更用@AutoMigration，复杂变更手写Migration

## 工程规范
- 每次修改必须更新版本号，APK 输出为 `记账_v{versionName}_{buildType}.apk`
- API Key：local.properties(不提交)+BuildConfig注入，用户修改存DataStore优先
- allowBackup="true"，生产环境保留日志
